PK → Address Extractor (offline)

Derive alamat dari private key, salin semuanya sekaligus. Tidak ada fungsi kirim dana — alat ini hanya membaca/menghitung.
Keamanan: Semua private key diproses hanya di browser Anda, tidak dikirim ke server mana pun (halaman ini tidak punya backend).
• Jangan buka di device/browser yang tidak Anda percaya.
• Jangan screen-record / screen-share saat memakai.
• Tombol Clear menghapus semua dari memory + localStorage.
• Jika memakai "Cek saldo (Alchemy)": yang dikirim ke RPC hanya alamat, bukan private key.

Catatan offline

Untuk offline penuh: saat online, buka https://cdn.jsdelivr.net/npm/ethers@6.13.4/dist/ethers.umd.min.js, simpan sebagai ethers.umd.min.js di folder yang sama dengan file HTML ini, lalu ganti baris src= di atas menjadi src="./ethers.umd.min.js".
