4 · Cek saldo massal (batch JSON-RPC — disarankan Alchemy)

Cara kerja: banyak eth_getBalance dikirim dalam 1 request HTTP (JSON-RPC batch). Ini yang bikin ribuan alamat tetap aman dari 429. Kalau Alchemy menolak (batch terlalu besar), kecilkan batch size (mis. 25–50).
#AddressSaldo

Catatan

• Derive alamat: tanpa RPC → tidak ada limit jumlah.
• Cek saldo: minimal 1 alamat per request, tapi batch sampai 50 alamat/request → 1.000 alamat ≈ 20 request saja (jauh lebih aman).
• RPC publik (base.org dsb) biasanya membatasi batch & rate → untuk skala banyak, pakai Alchemy.
• Offline penuh: simpan ethers.umd.min.js di folder yang sama lalu ubah src jadi ./ethers.umd.min.js.
